# Chair

Chair is a free appointment diary for hairdressers, for Android. It has day, week and list views for every stylist, processing time left free for other bookings, time off and UK bank holidays blanked out, client records with colour formulas, skin tests and photos, repeat bookings, a waiting list, takings with a PDF report, home visits, widgets and password-locked backups. It has no adverts, no accounts and no paid version, and it cannot go online.
